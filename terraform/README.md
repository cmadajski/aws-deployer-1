# Terraform IAC for App Infrastructure Deployment

Terraform has become one of the primary ways to handle infrastructure deployment for applications. It allows for declarative and repeatable infrastructure setup with minimal hassle. This is especially true for AWS projects since AWS is a first-class collaborator with Hashicorp. I have learned the hard way that there are MANY 3rd party Terraform providers that are no where close to as good as the AWS provider.
